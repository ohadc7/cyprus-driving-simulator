# Cyprus Driving Simulator — v0.1.0

משחק דפדפן בעברית לתרגול נהיגה בצד שמאל, עם מבט ממושב הנהג ודשבורד.

## הפעלה

פתחו את `index.html` בדפדפן מודרני. לא נדרשים התקנה, חשבון או שרת.
אפשר גם להגיש את התיקייה כאתר סטטי, כולל דרך GitHub Pages.

## שליטה

- ↑ האצה; ↓ בלימה; ← → היגוי.
- רווח להשהיה; V להצגת מפת הצומת או לסגירתה.
- לחצני המסך תומכים גם בהחזקה במגע.
- לחצו על ״התחל נהיגה״ כדי למקד את המקלדת במשחק.

## תכונות

- מסלול מתמשך עם פניות, כיכרות, השתלבות, יציאה ממחלף ועקיפה.
- שלוש רמות צפיפות תנועה, לבחירה בתחילת נסיעה.
- מראות צד חיות ומפה קטנה לפני צומת ולאורך השתלבות.
- היגוי מסייע בקטעים ישרים וזמן לתיקון סטייה מהנתיב.
- התנגשות עוצרת את הרכב ומוסיפה פסילה; המשחק מסתיים בחמש פסילות.

## פיתוח ובדיקות

הקוד והעיצוב של המשחק נמצאים ב־`src/game.html`. לאחר שינוי:

```sh
python3 build.py
node tests/collisions.cjs
```

`src/standalone-template.html` מכיל את מעטפת התצוגה העצמאית. `index.html` הוא התוצר המוכן להפעלה. הבדיקות דורשות Node.js וכוללות זיהוי התנגשות בין פריימים, פגיעה מהצד, חלון תצוגת ההשתלבות וסיום בחמש פסילות.

## גבולות הגרסה הראשונה

זהו משחק תרגול עם כבישים, תנועה ופיזיקה מפושטים. הוא אינו מדמה את כל כללי התנועה, השילוט או התנהגות הנהגים בקפריסין. סל״ד והילוך מוצגים לצורך ההדמיה. בדיקות הקוד אינן מחליפות בדיקת משחק ידנית בדפדפן.
